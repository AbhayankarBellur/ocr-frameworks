3.2.1 Scaled Dot-Product Attention
We call our particular attention "Scaled Dot-Product Attention" (Figure 2). The input consists of
queries and keys of dimension d;, and values of dimension d,. We compute the dot products of the
query with all keys, divide each by dx, and apply a softmax function to obtain the weights on the
values.
In practice, we compute the attention function on a set of queries simultaneously, packed together
into a matrix Q. The keys and values are also packed together into matrices K and V. We compute

The two most commonly used attention functions are additive attention [2], and dot-product (multi-

of TE: Additive attention computes the compatibility function using a feed-forward network with
